# Share-card editorial and production notes

All 74 jokes in posts.json are original writing for this collection. No individual joke or comic text was copied or adapted verbatim. The pages therefore do not attribute invented text to an outside writer. Each author name and handle is fictional; each portrait was generated for this project. There are no verification badges, fabricated engagement counts or links that imply these profiles exist on X.

Humor research considered the Protolol tradition of turning technical rules into a social misunderstanding, CommitStrip's workplace satire and PHD Comics' treatment of waiting, bureaucracy and procrastination. The useful pattern was a specific technical premise followed by an unexpected human consequence, rather than adding a generic coding pun to every title. The jokes stay about the task situation, not the solution technique. Examples include a zero cancelling its row and column as an incident-response policy, minimum meeting-free days as a fantasy genre, and tree roots taking leadership credit for the deepest leaves' contributions.

Sources inspected on 2026-11-13, client local date: https://github-wiki-see.page/m/kyrylo/xtopherus/wiki/Help for the Protolol reference; https://ufies.org/archives/2011_09.html for archived protocol-humor context; https://www.commitstrip.com/en/2016/08/25/a-very-comprehensive-and-precise-spec/ and https://www.commitstrip.com/en/ for developer-workplace satire; https://phdcomics.com/comics/aboutcomics.php and https://phdcomics.com/comics/most_popular.php for research/procrastination themes. The original Protolol text archive at https://attrition.org/misc/ee/protolol.txt could not be decoded by the web reader; no text from that failed retrieval was used.

Metadata follows the primary Open Graph reference at https://ogp.me/: canonical URL, title, type, image, description and image MIME type/dimensions/alternative text are embedded directly in each HTML head. The JPEGs are 1200x630, with per-problem names and content. Twitter-style large-image metadata is included for compatible readers. No account handle is asserted through twitter:site or twitter:creator. The final presentation and caching behavior remain under each receiving platform's control.

The JPEGs are deterministic renders of a dedicated compact social layout using Pillow, not AI-generated text and not browser screenshots. Their content, portraits, artwork, palette and hierarchy match the HTML post data. Controls and the task-summary line are omitted to give the message more room in a shared preview. render-social-previews.py writes layout measurements, hashes and byte counts to preview-manifest.json and rejects overflow. All 74 outputs were reviewed in contact sheets; the first card was also inspected at full resolution.

Portraits were generated as four 5-by-4 contact sheets. The first74 cells were extracted in inventory order, resized to 192x192 and saved as optimized JPEGs. avatar-sheets/ retains the original generated sheets; avatar-production.json records the main brief. Runtime portraits are in dist/assets/avatars/. Existing problem illustrations were reused unchanged. The four original recurring-character reference sheets remain in references/.

To update sharing content, edit posts.json; run node scripts/build-share-pages.mjs and python scripts/render-social-previews.py; run node scripts/build-offline.mjs after runtime changes. Run the Node tests and python scripts/validate-sharing.py. Inspect changed JPEGs at full size and check the live page before publication. Do not replace problem-specific text with a repeated caption or expose research-ledger solutions.
