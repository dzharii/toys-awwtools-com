## Reproduce

From this project directory:

```sh
dotnet build --configuration Release
dotnet run
dotnet run -- --yes,please,proceed

dotnet build examples/specification-workflow/SpecificationWorkflow.csproj --configuration Release
dotnet build examples/static-web-design/StaticWebDesign.csproj --configuration Release
dotnet build examples/enterprise-csharp/EnterpriseCSharp.csproj --configuration Release
```

Run an example from its own folder. The default prints a dry-run plan. Pass `--yes,please,proceed` to enable execution. If the selected instruction file is missing, it is created atomically after preflight checks. If it already exists—as `AGENTS.md` does in each checked-in example—the live run also requires the exact reply `yes, please proceed`; reply `no` to stop.
