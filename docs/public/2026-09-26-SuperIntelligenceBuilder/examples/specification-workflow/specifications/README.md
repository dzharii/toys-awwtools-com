# Specifications

Specifications are organized by feature. Each feature keeps product behavior, technical planning, and implementation tasks in separate files.

| Feature | Product specification | Technical plan | Tasks | Status |
| --- | --- | --- | --- | --- |
| Bulk CSV task import | [spec.md](csv-task-import/spec.md) | [plan.md](csv-task-import/plan.md) | [tasks.md](csv-task-import/tasks.md) | Ready for product decisions and implementation planning |

## Workflow

Read the [project constitution](../.specify/memory/constitution.md), then review a feature in this order: specification, plan, tasks. Product-affecting open questions in the specification must be resolved before implementation.
