Example 02 / Art direction

Choose the idea before polishing the page.

This example asks an agent to understand a repair cafe, compare three visual theses, justify one direction, record reusable decisions, and build a dependency-free static site.

Open generated siteDownload Program.csDownload project file

Design as an auditable decision

The agent chose "Mended Field Notes" after comparing it with a blueprint and patchwork direction. It then built the Juniper Street Repair Cafe page with semantic HTML, local CSS, progressive JavaScript, visible focus, reduced motion, and honest placeholders for facts that were not supplied.

Research basis

The process combines the strong art-direction emphasis of Anthropic's popular frontend-design skill with the accessibility and interaction review of Vercel's web-design-guidelines skill.

The live run found its own initial contrast failure (3.64:1), darkened the accent, and revalidated the core palette at 4.72:1 or better. JavaScript syntax, HTML structure, local references, ARIA references, responsive rules, and reduced-motion behavior also passed static checks.
