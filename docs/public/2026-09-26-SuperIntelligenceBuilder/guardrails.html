Consequential actions / deliberate words

A polite request is not consent.

An existing instruction file may contain carefully maintained project policy. Before an agent can revisit that workspace, the builder explains the risk and requires an exact, intentionally asymmetric reply.

The confirmation ceremony

If the Markdown instruction file already exists, execution pauses before agent discovery. The longer phrase grants permission; the shorter answer retires the request. 

To continue:
yes, please proceed

To stop:
no

y, yes, capitalization changes, added whitespace, and every other approximation are insufficient. The prompt repeats until it receives one exact reply. End-of-input fails closed with ConfirmationRequired.

What consent means

It permits this one agent run to begin. It acknowledges that the fluent task may ask the agent to amend or replace the instruction file and other workspace files.

What it does not mean

It is not approval of every eventual edit, a rollback mechanism, or a substitute for reviewing the resulting diff and validation evidence.

Behavior by state

DefaultThe runner reads and reports the plan. It does not probe, launch, create, or edit anything.
Execution flagThe main program must pass Options.Proceed = true; the samples do so only for --yes,please,proceed.
Existing fileAfter the execution flag, the exact interactive phrase is still required before CLI probing.

Civilised, but still precise

User-facing builder failures are rendered as “A Regrettable Circumstance” with a stable diagnostic number, while retaining the original technical cause and typed ErrorCode. Internal implementation remains normal C#; the themed names CeremonialConsent and Civilise are small, readable adapters rather than a new language.

The voice is inspired by Christian Hofstede-Kuhn's Bespoke: A Programming Language for People Who Say Please. SuperIntelligenceBuilder does not implement Bespoke, copy its proposed syntax, or claim affiliation; it adapts the central joke that software can remain exact while speaking with manners.

Validated cases: the default produced a dry-run plan without edits; y and yes were rejected; no returned a declined result without creating a run; EOF failed closed; the exact approval phrase advanced to agent resolution; and dry-run mode remained non-interactive.
