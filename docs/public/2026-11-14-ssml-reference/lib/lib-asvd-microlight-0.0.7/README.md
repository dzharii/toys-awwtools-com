# microlight 0.0.7

Vendored syntax-highlighting scanner by asvd, licensed under MIT.
Upstream: https://github.com/asvd/microlight

Copied from this repository's
`2026-09-13-300K-stars-skill-language-editor/lib/lib-asvd-microlight-0.0.7/`
reference material. This folder contains its own copy; the browser does not
load any files from that project or the upstream site.

color calculations. The scanner and source-text preservation are unchanged.
