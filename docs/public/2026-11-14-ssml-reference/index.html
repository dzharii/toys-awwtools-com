    SSML reference

    Control pronunciation, timing, and delivery in text-to-speech applications.

    Azure Speech SSML 1.0 + Microsoft extensions. Sources checked 14 November 2026.

    01 Start here

    SSML is XML input to speech synthesis, not an audio format. It controls pronunciation and timing. Choose a voice that supports the controls you need: different engines or voice families may ignore or reject the same tags.

    This page uses Azure's SSML 1.0 dialect. The W3C also publishes SSML 1.1; that does not mean Azure accepts every 1.1 feature.

    I have a script

    Copy the document below. Use Audio Content Creation to hear it, then adjust one control at a time.

    I am building an app

    Start with the Python SDK sample. Choose pre-rendered, on-demand, or conversational audio based on when the text changes.

    I need a specific effect

    Find the control, check voice compatibility, then load an example into the local editor.

    A complete Azure document

    Standard neural

    en-US-JennyNeural is a non-HD voice used for the timing examples. Check availability in your resource's region.

    <speak version="1.0"
       xmlns="http://www.w3.org/2001/10/synthesis"
       xmlns:mstts="https://www.w3.org/2001/mstts"
       xml:lang="en-US">
  <voice name="en-US-JennyNeural">
    <p>Welcome to the <sub alias="speech synthesis markup language">SSML</sub> reference.</p>
    <p>Read the example.<break time="400ms"/>Then change one setting.</p>
  </voice>
</speak>

    Expected effect: expand the abbreviation, separate the paragraphs, and pause at the explicit break. Natural punctuation also affects timing.

    Hear an example in Foundry

    1. Copy a complete SSML document from this page or download it as UTF-8 text.
    2. Open your project in Microsoft Foundry (also called Azure AI Foundry). Go to Playgrounds > Speech playground > Text to speech > Audio content creation.
    3. Create a tuning file and paste the document, or use Upload > Text file with the downloaded .txt. Choose a supported voice and preview with Play.
    4. Adjust the script, stop and replay to regenerate, then save or export WAV/MP3 when satisfied.

    Requires an Azure subscription, project/resource permissions, and a supported voice. Synthesis uses your Azure resource and can incur charges. The tool accepts up to 20,000 characters per tuning file. Official workflow and limits.

    Alternative: Speech Studio Audio Content Creation with a Speech resource. Foundry resources are not supported in Speech Studio. Use the Voice Gallery to compare personas before tuning.

    02 Syntax & controls

    An Azure document has one <speak> root, version="1.0", a default SSML namespace, xml:lang, and at least one named <voice>. Add the mstts namespace when using Microsoft extensions. Namespace URIs identify vocabularies; they are not API endpoints.

    Choose a control by the effect you need
    NeedElement / settingMeaning and caution
    Group thoughtsp, sParagraph and sentence boundaries. Ordinary punctuation is often enough.
    Pause at a positionbreak time="400ms"Explicit pause in seconds or milliseconds. Azure allows 0-20,000 ms; time overrides strength.
    Speak digits or datessay-as interpret-asInterpret the enclosed text as a data type. Date/time formats and interpretations are locale-dependent.
    Expand an abbreviationsub aliasSpeak the alias instead of the enclosed text. Good first choice for product names and acronyms.
    Specify exact soundsphoneme alphabet phUse the voice locale's phone set. Keep readable text inside the element.
    Reuse a pronunciation dictionarylexicon uriReference a service-accessible PLS/XML file. It is a separate document, not an inline SSML dictionary.
    Change speed or pitchprosody rate pitch volumeAdjust a span, preferably a sentence. range and contour add pitch shaping; HD models do not support this element.
    Stress a wordemphasis levelreduced, none, moderate, strong. Azure word-level emphasis is limited to specific voices.
    Change speaking languagelang xml:langUse a multilingual voice that supports the language. Does not translate the text.
    Choose a personavoice nameA voice name selects both persona and model family. Several sibling voice elements can form a dialogue.
    Add a sound clipaudio srcThe service fetches the clip. Keep spoken fallback text. Requires a supported model and compatible audio asset.
    Synchronize application statebookmark markEmit a silent SDK event at a script position; not an audible pause.

    XML rules that prevent common failures

    • Escape literal & as &amp;, < as &lt;, and > as &gt;. In quoted attributes, escape the matching quotation mark as &quot; or &apos;.
    • Quote attribute values and close every tag. HTML tags such as <b> and <br> are not SSML controls.
    • Keep prose as text, not raw markup, when inserting data into a template. XML escaping and JSON escaping are separate steps.
    • Source newlines are not a portable pause control. Use punctuation, structural elements, or a supported break.
    • An XML comment documents intent for an editor; it does not direct the voice. Avoid DTDs and external entities.

    Which voice family to start with

    Standard neural
    Start here for explicit pauses, speed/pitch adjustments, pronunciation control, or SDK bookmarks. Styles and roles are per-voice; consult the styles/roles list.
    Dragon HD / Omni
    Use for contextual, expressive narration when the smaller control set is acceptable. For example, en-US-Andrew:DragonHDOmniLatestNeural is not interchangeable with en-US-AndrewNeural. LatestNeural tracks model updates, so output can change over time.
    Dragon HD Flash
    A separate HD variant with voice-specific styles and language/region restrictions. Use its own capability list; do not extrapolate from Omni.
    MAI-Voice-2.1 / Flash
    Public preview as of the source check. Uses SSML with model-specific voices and styles, such as happiness. Do not transfer Dragon or Jenny style tokens blindly. Voice cloning is gated and requires authorized, consented voices.
    OpenAI voices
    The Azure OpenAI audio API does not support SSML. OpenAI voices exposed through Azure Speech support a subset. Same persona, different API contract: a Foundry project alone does not make an audio endpoint SSML-capable.

    Before deployment: verify the regional voices API, regions, and language support. Neither this page nor a local XML check can confirm that a voice is provisioned.

    Microsoft extensions: when they are useful

    Extensions are not portable W3C controls
    ExtensionUse and constraints
    mstts:express-asSpeaking style; selected standard voices also support styledegree (0.01-2, default 1) and role. Unsupported styles can fall back to neutral delivery.
    mstts:silenceLeading, trailing, or sentence-boundary silence across a voice block. -exact types replace natural silence; ordinary types add to it.
    mstts:backgroundaudioMix a service-accessible music/ambient asset under speech. Place under speak, not voice. Standard neural; check file requirements.
    mstts:audiodurationFit speech to a target duration within documented bounds. Standard neural; not a universal substitute for editing the script.
    mstts:visemeRequest supported facial/mouth output for animation. Needs SDK event handling and a supported voice/locale; it does not animate a UI by itself.
    mstts:dialog, mstts:turnContext-aware dialogue with a specific multi-talker model, rather than arbitrary named standard voices.
    mstts:markdown, mstts:prompt, mstts:mathspeechverbositySpecialized Markdown/math reading. See the pronunciation guide for voice, locale, and format restrictions.
    mstts:ttsembedding, mstts:voiceconversionPersonal voice / voice conversion workflows, not general narration controls. Check access and consent requirements before designing around them.
    voice parametersModel-specific generation settings such as Omni temperature. These are not generic SSML prosody attributes.

    04 Examples

    Most examples show the content inside a voice block. With JavaScript enabled, Load complete SSML adds the correct document wrapper and example voice in the editor. Without JavaScript, place the snippet inside the starter document and use the voice stated on the example.

    Paragraphs & sentences

    Standard / HD / Omni
    <p><s>The build passed.</s> <s>Review the release notes.</s></p>
<p>Next, deploy to staging.</p>

    Separate thoughts, not every phrase. Punctuation already provides natural sentence boundaries.

    An explicit pause

    Standard / Dragon HD
    Check the region.<break time="600ms"/>Then retry.

    Hear a pause between the instructions. Not supported by Dragon HD Omni; use natural phrasing there.

    Expand an acronym

    Standard / HD / Omni
    Call the <sub alias="application programming interface">API</sub>.

    Hear the expansion instead of "API". An alias is easier to maintain than phonetic spelling when exact sounds are unnecessary.

    Digits, ordinals & dates

    Standard / HD / Omni
    Code: <say-as interpret-as="characters">2048</say-as>.
Attempt <say-as interpret-as="ordinal">3</say-as>.
Date: <say-as interpret-as="date" format="ymd">2026-11-14</say-as>.

    Distinguish "two zero four eight" from a cardinal number. The date's spoken wording depends on the locale.

    Slower delivery

    Standard neural
    <prosody rate="-15%" pitch="+2st">
  Keep a copy of the original configuration.
</prosody>

    Reduce rate and raise pitch by two semitones. Compare rate alone first; avoid changing every dimension at once.

    A pronunciation override

    Standard / Dragon HD
    <phoneme alphabet="sapi" ph="iy eh n y uw eh s">en-US</phoneme>

    An English SAPI phone sequence for "en-US". Use the locale's phonetic alphabet; arbitrary IPA/SAPI sequences can fail.

    A restrained speaking style

    JennyNeural
    <mstts:express-as style="cheerful" styledegree="0.5">
  Your export is ready.
</mstts:express-as>

    Request a softer cheerful delivery. styledegree only works when supported by the selected voice.

    Word-level emphasis

    GuyNeural
    Keep the <emphasis level="strong">original</emphasis> file.

    Request extra stress on "original". The voice guide lists Guy, Davis, and Jane neural voices for word-level emphasis. Do not substitute Jenny or an HD voice.

    A multilingual sentence

    AvaMultilingualNeural
    The greeting is <lang xml:lang="es-ES">buenos días</lang>.

    Switch the pronunciation language while keeping a multilingual persona. Translation must happen before synthesis.

    Silence at sentence boundaries

    Standard neural
    <mstts:silence type="Sentenceboundary-exact" value="500ms"/>
The upload finished. The review can begin.

    Set boundary silence across the enclosing voice block. Unlike break, this is not a marker placed between arbitrary words.

    A synchronization marker

    Standard neural + SDK
    <bookmark mark="step-2"/>Now open the settings panel.

    Listen for the SDK's BookmarkReached event to highlight a step. The marker itself is silent. Use its audio offset, not event-arrival time.

    An external sound with fallback

    Asset required
    <audio src="https://YOUR-HOST.example/cue.wav">
  The notification sound is unavailable.
</audio>
Your export is ready.

    Replace the placeholder URL. Azure must be able to fetch a compatible file. The element's text is spoken if the clip cannot play. Check audio requirements.

    Expressive Omni narration

    Dragon HD Omni
    <p>The first test did not pass.</p>
<p><mstts:express-as style="encouraging">We have isolated the cause. Let's try again.</mstts:express-as></p>

    Uses en-US-Andrew:DragonHDOmniLatestNeural, not Jenny. The complete document includes Omni's documented default parameters. There is no break or prosody.

    A multi-talker exchange

    Specific model / preview
    <speak version="1.0" xml:lang="en-US"
       xmlns="http://www.w3.org/2001/10/synthesis"
       xmlns:mstts="https://www.w3.org/2001/mstts">
  <voice name="en-US-MultiTalker-Ava-Andrew:DragonHDLatestNeural">
    <mstts:dialog>
      <mstts:turn speaker="ava">What changed in this release?</mstts:turn>
      <mstts:turn speaker="andrew">We added an offline export.</mstts:turn>
    </mstts:dialog>
  </voice>
</speak>

    The model retains dialogue context across turns. Speaker IDs belong to this model. Check multi-talker availability rather than inventing IDs.

    A reusable pronunciation lexicon

    Save the separate file below as terms.pls and host it where Azure can fetch it. Reference it inside a voice with <lexicon uri="https://YOUR-HOST.example/terms.pls"/>. The placeholder is not runnable. For HD/Omni, use alias entries rather than phonemes.

    <lexicon version="1.0" alphabet="ipa" xml:lang="en-US"
         xmlns="http://www.w3.org/2005/01/pronunciation-lexicon">
  <lexeme>
    <grapheme>SDK</grapheme>
    <alias>software development kit</alias>
  </lexeme>
</lexicon>

    Entries are case-sensitive and each lexicon is for one locale. Azure documents a 100 KB maximum and a URI-keyed cache of up to 15 minutes; version the URL when publishing a revised dictionary. Lexicon rules and validation tool.

    Omni generation settings

    These go in the parameters attribute of voice, separated by semicolons. Use them only with the documented model.

    Dragon HD Omni parameter reference
    ParameterDefaultRangePurpose
    temperature0.70.3-1.0Generation variation; lower is more stable, not guaranteed identical.
    top_p0.70.3-1.0Filter candidate outputs for diversity. Microsoft recommends matching temperature.
    top_k221-50Limit the number of candidate outputs.
    cfg_scale1.41.0-2.0Context alignment and speed; not a portable substitute for prosody rate.

    Official parameter ranges. Other HD families have different settings. Square-bracket style markers such as [excited] are also model-specific syntax, not W3C SSML; unsupported voices may read them aloud.

    05 Check & share SSML

    This editor runs locally. It does not synthesize audio or contact Azure. Check the document, copy or download it, then paste/upload it into Audio Content Creation or your Foundry project.

    Check XML tests well-formedness, the Azure document wrapper, and common HD incompatibilities. It is not a full SSML schema, pronunciation, style, region, or service validator. Editor limit: 20,000 characters; share-link limit: 6,000 UTF-8 bytes.

    Share only public scripts. A share link contains readable script data in the URL fragment, not encrypted storage. Anyone with the link can recover it; browser history and clipboard can retain it. Nothing is uploaded by this page.

    Can a link preload Foundry?

    No public, documented SSML-preload URL was found in the checked Foundry / Speech Studio workflow. This page's share link opens this editor, not an Azure project. Copy or upload the script after signing in; use your own project's portal URL only as a navigation link for collaborators who already have access.

    Do not put resource keys in URLs, embed a portal session, or treat project links as permission grants. A static page cannot silently create a project or issue authorized, billable synthesis requests.

    06 Call Azure Speech

    Use the Speech SDK for synthesis and timing events. Choose a supported voice in the SSML itself. The SDK's plain-text method is not interchangeable with its SSML method.

    SSML entry points
    ClientCallUse

    C#await SpeakSsmlAsync(ssml)Server/desktop integrations and SDK events.

    Python: audio file + bookmark timings

    Download synthesize.py and narration.ssml into the same directory. Use Python 3.9+ with the Speech SDK's platform prerequisites. Set SPEECH_KEY and SPEECH_REGION in your local environment; do not commit them.

    python -m pip install azure-cognitiveservices-speech
python synthesize.py narration.ssml --output narration.wav
    import argparse
import json
import os
from pathlib import Path
import xml.etree.ElementTree as ET

import azure.cognitiveservices.speech as speechsdk

parser = argparse.ArgumentParser()
parser.add_argument("script", type=Path)
parser.add_argument("--output", type=Path, default=Path("narration.wav"))
args = parser.parse_args()
ssml = args.script.read_text(encoding="utf-8")
if "<!DOCTYPE" in ssml.upper() or "<!ENTITY" in ssml.upper():
    raise SystemExit("DTD and entity declarations are not allowed.")
root = ET.fromstring(ssml)
if root.tag != "{http://www.w3.org/2001/10/synthesis}speak":
    raise SystemExit("Expected an SSML speak root.")

config = speechsdk.SpeechConfig(
    subscription=os.environ["SPEECH_KEY"],
    region=os.environ["SPEECH_REGION"],
)
config.set_speech_synthesis_output_format(
    speechsdk.SpeechSynthesisOutputFormat.Riff24Khz16BitMonoPcm
)
audio = speechsdk.audio.AudioOutputConfig(filename=str(args.output))
synth = speechsdk.SpeechSynthesizer(speech_config=config, audio_config=audio)
markers = []
synth.bookmark_reached.connect(lambda event: markers.append({
    "mark": event.text,
    "seconds": event.audio_offset / 10_000_000,
}))
result = synth.speak_ssml_async(ssml).get()
if result.reason != speechsdk.ResultReason.SynthesizingAudioCompleted:
    raise SystemExit(f"Synthesis failed: {result.cancellation_details}")
args.output.with_suffix(".timing.json").write_text(
    json.dumps(markers, indent=2), encoding="utf-8"
)
print(f"Saved {args.output} and bookmark timings.")

    The output is 24 kHz mono PCM WAV plus a .timing.json sidecar. SDK offsets are 100-nanosecond ticks: divide by 10,000,000 for seconds. Events can arrive ahead of playback; schedule against the audio player's clock. A voice without bookmark support will not produce these markers.

    This is a local/server learning sample, not a public synthesis endpoint. A deployed service also needs authentication, rate/length limits, allowlisted voices and asset URLs, cancellation handling, and bounded retries. Prefer Microsoft Entra authentication where supported. No Azure credentials are requested by this website.

    REST request shape

    POST https://YOUR-RESOURCE.cognitiveservices.azure.com/cognitiveservices/v1
Ocp-Apim-Subscription-Key: <read from server environment>
Content-Type: application/ssml+xml
X-Microsoft-OutputFormat: riff-24khz-16bit-mono-pcm
User-Agent: your-application

<complete SSML document as UTF-8 request body>

    Replace the host with your Speech resource's configured endpoint; use the REST reference for regional/custom-domain and authentication requirements. Match the declared output format to the audio player and file extension.

    Batch input shape

    {
  "inputKind": "SSML",
  "inputs": [
    { "content": "<complete escaped SSML document>" }
  ],
  "properties": {
    "outputFormat": "riff-24khz-16bit-mono-pcm"
  }
}

    This is a request-body shape, not runnable content. Serialize JSON with a library instead of hand-escaping XML strings. The batch synthesis API is generally available; HD voices are documented as real-time only. Do not assume any voice that works in an interactive playground works in batch.

    07 Application patterns

    These are implementation patterns to adapt, not a required Azure topology. Keep content separate from rendering: store text and intent, then render provider-specific SSML at the synthesis boundary.

    On-demand speech: changing text

    Pre-rendered audio: fixed content

    Include the script, voice, locale, model version/name, generation settings, output format, and lexicon revision in a build manifest/cache key. Keep a last-known-good render. Model updates and sampling mean the same SSML is not a promise of byte-identical audio.

    Foundry + an LLM: generated responses

    Have the LLM return text or structured speech segments, not unrestricted SSML. Render SSML server-side: escape text, select allowlisted voices/styles, and check length and capabilities before calling Azure Speech. Send audio to the client; keep resource keys server-side.

    {
  "locale": "en-US",
  "preset": "help-neutral",
  "segments": [
    { "text": "The export is ready.", "pauseAfterMs": 400 },
    { "text": "Keep the original file." }
  ]
}

    The renderer resolves help-neutral to a configured standard neural voice, validates the pause range, and escapes each text segment. If the target model has no break, reject the request or explicitly select a different rendering policy; do not silently promise an equivalent effect.

    Pre-render fixed prompts; synthesize changing text. Sentence-sized chunks reduce waiting, but each SSML request must be a complete document and may lose cross-sentence expressive context. Keep a bounded playback queue, cancel obsolete requests, and stop audio when the user interrupts. Do not split XML at a character count.

    For a managed, real-time conversational stack, evaluate Voice Live separately. It handles a different end-to-end interaction contract; do not assume its session accepts arbitrary SSML documents. For an actual prototype, inspect Microsoft's document-to-podcast sample; it demonstrates direct LLM-to-SSML generation, not the policy boundary recommended here.

    When supporting multiple speech providers

    Define a small internal model such as text, pronunciation alias, pause, locale, and delivery preset. Implement one renderer and capability profile per provider/model. mstts:express-as, Alexa's amazon:emotion, and Google-specific elements are not equivalent. Make unsupported features explicit and test the rendered audio on every target.

    08 Troubleshooting

    Diagnose the symptom before adding more tags
    SymptomCheck firstNext action
    XML error / HTTP 400Unescaped text, namespaces, root/voice, malformed phonemes, unsupported elements.Run Check XML, then retry the smallest complete document against the actual service.
    Tag has no audible effectExact voice family, supported style, and whether you called an SSML or plain-text method.Compare tagged vs. plain versions using the same voice. A neutral fallback is not proof of support.
    Pause/rate control fails on Omnibreak / prosody are not supported.Use a standard neural voice when explicit timing is required; use natural phrasing for Omni.
    Pronunciation remains wrongLocale, acronym interpretation, phone set, case-sensitive lexicon match.Try sub first; for a lexicon, check URL access and cache revision.
    Asset/lexicon cannot loadService-side access, media format, expired SAS, and XML-escaped query parameters.Provide a service-accessible, allowlisted URL and compatible file. A local file path is not a hosted asset.
    401 / 403Resource host/region, credential type, token expiry, and permissions.Follow the resource's authentication path; do not reuse a token across incompatible endpoints.
    429 / latency spikesRequest rate, voice capacity, concurrent work, and retry storms.Bound concurrency, back off with jitter, honor retry guidance, and cache stable prompts when appropriate.
    Audio won't playOutput encoding, sample rate, container, MIME type, and extension.Save WAV with a RIFF format or MP3 with an MP3 format; raw PCM is not a WAV file.
    Caption/highlight driftSDK tick conversion and event time versus actual audio playback time.Use audio_offset / 10_000_000 seconds against the player's clock. Word text offsets may refer to the SSML source, not display text.

    A small audio regression loop

    Keep a script containing names, dates, acronyms, a paragraph transition, and an ordinary sentence. Save a plain baseline, change one control, and audition both at the same playback level. Check pronunciation, pacing, intelligibility, and the actual timing metadata. Retain reviewed renders and the generation manifest.

    Do not assert byte-for-byte equality for generative audio. Use structural tests for rendered XML and timing invariants, plus human listening for delivery. XML validity alone cannot prove acoustic quality.
