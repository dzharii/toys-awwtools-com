# ILUD - The Folio

A brass-bound collection of paper field notes. Swipe the active paper, use its arrows, or turn through the side index. Every note opens an actionable remedy with source links and limitations.

Open `index.html` through any static web server. All runtime files, fonts, research data, and artwork are local to this folder; no build or other application is required.

Search (`/` or Ctrl/Cmd+K) covers the whole catalogue. Saved notes and optional sound stay in this browser. Reduced motion is respected. `reference.png` is the supplied creative direction, not the interface background. `screenshot.jpg` shows the finished application.

The original paper, binding, eyelets, and icons are CSS/SVG artwork. Fonts are distributed with their SIL Open Font Licenses in `assets`. Source review is not a guarantee of live service behavior. For another deployment URL, update the canonical and social metadata in `index.html`.
