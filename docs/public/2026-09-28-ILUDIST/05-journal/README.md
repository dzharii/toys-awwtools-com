# ILUD - The Quiet Journal

A cream-and-oxblood editorial guide with twelve indexed chapters. Swipe the opening spread or use chapter arrows and the margin index. Each featured story opens a practical action; additional articles compare alternatives.

The architecture, shadow study and still life are original SVG illustrations. There are no third-party image requests. All scripts, fonts, licenses and data are local to this folder; serve it as a static website without building.

The index, search, reading list, source disclosures and action forms work with keyboard and touch. The page-turn reveal respects reduced motion. Sharing assets include wide, X and square JPEG compositions, and `reference.png` preserves the supplied direction.
