# ILUD - The Wayfinder

Three working route lines distinguish changing a setting, avoiding a feature, and choosing an alternative. Selecting a stop changes the map's ticket; the departure board filters by activity and reaches every catalogue entry.

Serve this self-contained directory. Original SVG trackwork and valley engraving are local, as are fonts, data, and scripts. Line origins and stops are keyboard-accessible buttons. Motion traces a chosen route but never blocks interaction. Search and browser-local saved fixes are available from the header.

The approved reference is `reference.png`. Social images are deliberately composed in three formats. Source-review dates and platform limitations appear on each remedy. Update canonical and sharing URLs for a different deployment.
