# ILUD - The Three Doors

An architectural accordion with three genuinely different approaches: switch a feature off, work around it, or use an alternative. Open a door to browse its relevant activities, then cycle through remedies. Each door remembers its selected activity while the page remains open.

Arched molding, hinged side leaves, lights and tiled thresholds are original CSS artwork. Buttons expose expanded state and labelled regions. Keyboard activation works everywhere; reduced motion skips the spatial entrance.

Serve this self-contained folder on any static host. The catalogue, fonts, sources, icons, reference and publishing images are local. Saved fixes stay in this browser. No door changes an external setting; the next step always explains the actual action.
