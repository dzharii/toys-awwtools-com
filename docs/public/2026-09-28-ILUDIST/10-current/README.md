# ILUD - The Quiet Current

An original celestial landscape with three flowing paths. Tap an activity, choose a branch, or carry the lantern to a destination. Arrow keys, Home and End on the lantern offer the same selection without dragging. Follow the illuminated thread to a remedy and cycle through alternatives.

The SVG currents are laid out from the actual button positions after font loading and resizing. Stars, planets, mountain layers, etched terrain and distant architecture are original artwork, not a reference-image backdrop. Reduced motion skips the illumination sequence.

This independent folder contains its own catalogue, fonts, scripts, icons and sharing images. Serve it over HTTP. It requests no device permissions. Saves are local; query words leave only when the user opens the named destination. Source notes explain uncertainties and platform restrictions. The supplied reference is included as `reference.png`.
