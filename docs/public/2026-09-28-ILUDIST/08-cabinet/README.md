# ILUD - The Useful Cabinet

Choose an instrument from the walnut rack. Its handle lifts from its socket and a practical remedy arrives on the workbench. The lower drawer holds six more activities. Previous and Next cycle through every fix for the selected tool; saving a fix pins it to the cabinet.

The cabinet uses original SVG brass instruments, glass, wood grain, CSS joinery, hardware, stationery and paper. It is not a screenshot with hotspots. There are no external runtime dependencies; serve this folder as a static site.

The wood engraving is rasterized from the included original `assets\wood.svg` to avoid repeatedly evaluating turbulence filters while scrolling on mobile WebKit. Reproduce it from the collection root with `node 08-cabinet\assets\art.mjs`. The dialog uses a dark backdrop without an expensive full-scene blur.

Each remedy includes provenance and limitations. Saves stay in this browser. All interaction works by button and keyboard, motion follows system preferences, and optional quiet sounds are available under About. The supplied reference and licensed local fonts are included.
