# ILUD - The Lantern Guide

A local decision tree, not a chat assistant. Choose a frustration, then an activity. The illuminated panel explains the next useful step; alternative doors and a phone-only filter refine it. Restart resets the path, and the complete catalogue remains searchable.

The architecture, heraldic panels, branch lines, paper illustration and icons are original CSS/SVG. All runtime files are local. Serve the folder as a static site. The guide requests no personal permissions, and its choices never leave the browser.

Every remedy retains sources and caveats. Saved fixes remain local. Keyboard buttons parallel the visual branches; reduced motion removes decorative entrance effects. Fonts include their licenses, and `reference.png` preserves the supplied direction.
