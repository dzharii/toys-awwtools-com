# ILUD - The Quiet Atlas

An original illustrated archipelago, with six islands per chart and two hemispheres covering all twelve activities. Selecting an island plots a route and reveals its landings. Zoom and bounded pan allow closer inspection without requesting location.

All code and assets are local. Serve the folder with any static web server. The illustration is generated deterministically by `node assets/art.mjs` from original SVG coastlines, topography, settlements, and botanical marks. No map tiles, third-party illustrations, or runtime network are required beyond links you choose to open.

Search, bookmarks, source notes and prepared actions complement the spatial navigation. Map destinations are real buttons; the chart can be used without dragging. Reduced motion suppresses route travel. Licensed fonts are in `assets`; supplied creative reference is `reference.png`.
