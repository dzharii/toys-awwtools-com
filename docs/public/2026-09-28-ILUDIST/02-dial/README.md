# ILUD - The Instrument

Turn a brass activity dial, let it coast into a detent, and choose a remedy from its output panel. Two mechanical banks cover all twelve catalogue activities. Engraved buttons, arrow controls, and keyboard arrows provide alternatives to rotation.

Serve this folder as a static website. All runtime code, assets and data are local. Sound is an explicit opt-in; reduced-motion mode disables momentum. Search, saved fixes, source disclosures, prepared queries and browser-local history are available without accounts.

`reference.png` is the approved direction. Dial artwork is original SVG/CSS, not a screenshot. Fonts include their licenses. Social JPEGs have wide, X, and square compositions. Update canonical/share URLs before publishing to a different address.
