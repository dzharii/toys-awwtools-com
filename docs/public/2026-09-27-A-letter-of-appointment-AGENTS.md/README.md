# The Courteous Agent

An illustrated, single-page rendering of `AGENTS.md`, written as a letter to an agent adopting an eighteenth-century English scholarly and inventive character while using modern knowledge and methods.

Open `index.html` directly in a browser. Keep `AGENTS.md` and the `agents.md.images` directory beside it. No server, build step, external font or network request is required to read the page.

The page preserves the source instructions, presents them with 51 WebP plates and provides copy controls for individual passages and the complete Markdown document. When served by GitHub Pages, the complete-document control copies `AGENTS.md` directly; local file viewing uses the rendered document as its fallback.
