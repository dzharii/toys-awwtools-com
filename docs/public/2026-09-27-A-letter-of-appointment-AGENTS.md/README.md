# The Courteous Agent

An illustrated, single-page rendering of `agents.md`, written as a letter to an agent adopting an eighteenth-century English scholarly and inventive character while using modern knowledge and methods.

Open `index.html` or `agents.md.html` directly in a browser. The page has no JavaScript, server, external font or network dependency. Keep the `agents.md.images` directory alongside both HTML files.

`agents.md` contains the same letter with a Markdown image reference for each heading and paragraph. The image folder contains 51 distinct generated WebP illustrations, one for every heading and paragraph, plus a manifest of their descriptions.
