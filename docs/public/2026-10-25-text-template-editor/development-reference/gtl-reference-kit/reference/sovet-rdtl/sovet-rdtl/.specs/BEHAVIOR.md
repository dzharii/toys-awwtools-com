# AX00. Разговор, история и локальные вложения

Новый чат немедленно получает одну opening-реплику без анализа ввода. Нумерация чатов возрастает, переписки изолированы, выбранный чат сохраняется. Текст ограничен 6000 символами. Enter отправляет, Shift+Enter добавляет строку, IME не приводит к случайной отправке. Пока ответ ожидает обычную задержку 500-1500 мс, повторная отправка блокируется. Пара обычных сообщений сохраняется до визуальной задержки, перезагрузка не вызывает другую генерацию.

Приоритеты: явная непосредственная опасность в сопровождающем тексте даёт только «(молчит)» до RNG; затем категория вложения; затем завершение; затем социальный аргумент и обычный тематический ответ/fallback. Риторический пример с крышей не равен реальному намерению. Содержимое медиа на опасность не анализируется.

Текст нормализуется только для поиска: NFC, регистр, е/ё и небольшой проверенный набор опечаток. История хранит оригинал. Границы слов предотвращают ложные темы. Учитываются отрицания, выполненные обязанности, ожидающая просьба и короткие продолжения. Чужое выполненное действие не засчитывается ребёнку. Благодарность с новым вопросом не завершает разговор; после настоящего прощания можно вернуться.

Целевые случайные выборы: три интонации поровну, common/odessa 50/50, core/extended 70/30, запрос длины 1/2/3 предложения 40/40/20, основная тема при нескольких совпадениях 70%. Сначала применяются смысловые и грамматические ограничения. Fallback и фактические доли записываются и измеряются отдельно, а не выдаются за точное достижение целей. Ответ не собирается из случайных несвязанных нравоучений.

Сервис передаёт ограниченный недавний контекст до 12 сообщений; анализ использует недавний эпизод, повторы оцениваются по последним пяти родительским ответам и familyId. При наличии альтернатив последние три конструкции исключаются до предпочтения слоя. Неоднократные уговоры могут усиливать раздражение, первая попытка не считается многократным спором. Подготовленные грамматические формы выбираются целиком.

Постоянная история поддерживает только текущую schemaVersion 2, ключ sovet-rdtl.state.v2. Повреждённое сообщение исключается отдельно, некорректный чат целиком, нечитаемый корень даёт пустое рабочее состояние. Миграций нет. Ошибка записи/квота сохраняет текущий разговор в памяти; конфликт вкладок не перезаписывается молча. Пользовательский текст создаётся текстовыми DOM-узлами.

Вложение необязательно сопровождается текстом и ограничено одним на отправку. Тип audio/image/file определяет один отрицательный ответ. Родитель не утверждает, что увидел/услышал/прочитал содержимое. Последовательные отправки одного типа повышают irritation до 3; другой тип или обычный обмен сбрасывают его. «Я уже сказал» и подобные формулы запрещены при первом событии.

Запись использует getUserMedia и MediaRecorder только после нажатия. В той же форме находятся активность, дорожка, таймер, отмена, остановка с прослушиванием и непосредственная отправка. Финальные данные ожидаются до формирования Blob. Отказ разрешения, отсутствие/занятость устройства, пустая или повреждённая запись дают техническую ошибку, без сообщений и родительской реакции. При переключении запись останавливается в прежний черновик, при скрытии страницы также останавливается. Поздно полученный отменённый stream сразу закрывается.

Плеер позволяет воспроизведение, паузу, повтор, перемотку, время и самостоятельное скачивание. Играет один плеер. Выбор файла и paste JPEG/PNG/WebP/GIF создают preview без автоотправки. Сигнатура/размеры проверяются до браузерного декодирования. Пропорции сохраняются; MIME URL берётся из проверенного растрового формата. Аудиоплейлисты не передаются проигрывателю. Неподдержанный аудиоимпорт становится file, видео и другие форматы тоже file. Обычный файл содержательно не читается, после подготовки остаются лишь временные метаданные.

Вся пара с вложением, включая подпись и ответ silence, временная: temporary и episodeId объединяют её. Адаптер до JSON исключает весь эпизод, не только бинарные данные. Нет localStorage/IndexedDB/серверного сохранения медиа. При переключении отправленные ресурсы живы; удаление, очистка и завершение страницы освобождают их. Отмена/удаление во время подготовки не могут восстановить ресурс позже. До отправки URL принадлежит черновику, после отправки чату. В движок не передаются Blob, URL и имя файла, включая history.

Пределы: изображение 12 МиБ, 20 мегапикселей, сторона 12000 px; аудио 20 МиБ и 180 с; обычный файл 25 МиБ; сессия 96 МиБ оценённой памяти с учётом декодированных изображений и 40 вложений. Мобильная пригодность этих пределов должна быть проверена. Не добавляются отдельные предупреждения о временности или объяснения технического хранения в обычный интерфейс.
