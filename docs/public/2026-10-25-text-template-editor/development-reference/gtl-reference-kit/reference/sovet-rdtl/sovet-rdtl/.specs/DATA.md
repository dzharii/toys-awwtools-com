# AW00. Данные, словари и грамматика

Источник истины: data/source/common.json, odessa.json и origins/common.json, origins/odessa.json. Оболочки содержат schemaVersion 1, contentVersion и массив expressions/origins. У выражений также есть catalogId на уровне каталога. Текущий корпус: 601 common и 279 odessa самостоятельных выражений, 6 технических шаблонов, 886 справок. Варианты и формы не увеличивают число самостоятельных конструкций.

| Поле выражения | Тип и назначение |
| --- | --- |
| id, library | Стабильный ID с префиксом common/odessa и соответствующая библиотека |
| canonical, variants | Основной текст и массив качественных вариантов одной конструкции |
| familyId, originId | Семейство повторов и ссылка на справку |
| topics, tones | Темы и допустимые ironic/strict/sarcastic |
| tier, weight | core/extended и положительный относительный вес |
| roles | standalone/opening/closing как роли при составлении |
| scenarios | normal/opening/closing/audio/image/file; функция независима от интонации |
| forms | Полные masculine/feminine формы, выбираемые целиком |
| irritation | Минимальный уровень для специальных повторных медиаотказов |
| requiresTopics, contextPattern, pendingTopics | Предпосылки применимости до случайного выбора |
| situations | Признание результата, обещание, помощь, позиция, уточнение, инициатива, метавопрос или новость |
| appendable, closingContext, repeatClosing | Разрешение составления и ограничения заключительных реплик |

Точная схема выражения находится в data/schema/expression.schema.json. scripts/catalog.mjs дополнительно проверяет ссылки, единообразие, количество, запрещённые обращения и домены. Технический isTemplate исключает запись из счётчика самостоятельных фраз. Один смысл можно переиспользовать в нескольких сценариях, не копируя запись.

Справка содержит id, expressionId, title, kind, summary, sources, verification, checkedAt и rights. kind: documented для проверенной точной конструкции, adapted для переработки, original для собственной формулировки, unverified для непроверенной старой атрибуции. checkedAt допускает null. Источник хранит библиографический title, evidence и checkedAt, при наличии url/author/id/independence/publishedAt/rights. Нет источника: не выдумывать его. Изменение документированной цитаты требует честной адаптированной атрибуции, исходное свидетельство не переписывается.

Ссылки на .ru и ru.* запрещены, кроме Wikipedia. Библиографическое название может остаться без URL. В пользовательской справке видны смысл и применение, а внутренние исследовательские поля остаются отделены. Современные медиаотказы не выдаются за исторические советские цитаты.

data/scenarios/topics.json задаёт темы, приоритеты, patterns и boost. data/rules/*.json содержат правила с ID, библиотекой, темой, priority, pattern, templates, expressionId, tones и ограниченными преобразованиями/captureMap. Преобразование покупки имеет преимущество перед общим цитатным переспросом. Неизвестное имя/объект сохраняется в цитате либо используется нейтральный ответ. Полной морфологии и произвольного изменения окончаний нет.

Результат движка содержит kind, text, tone, sourceLibrary, tier, expressionIds, familyIds, фактические parts, при наличии gender и диагностические поля выбора. Автор сообщения, функция и интонация не определяются UI по тексту. Формы используются в обычных ответах, вступлениях, завершениях и медиа. Пользовательская цитата не переписывается только потому, что в ней есть «вы».

Медиафонды покрывают не менее 24 common и 12 odessa на audio/image/file, в каждой категории есть все интонации и оба слоя. Вступления: минимум 24/12, завершения 36/15, реакции на подражание 20/8. Общий исторический core и современные тематические media-core считаются раздельно; общая статистика показывает оба. Независимая историческая приёмка не подменяется количеством записей.
