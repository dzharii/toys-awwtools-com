## Usage

Use badges for compact status and metadata: "Ready", "Draft", "Beta", "Synced", or "Blocked". Do not use badges as buttons. If a user can click it, it needs an interactive component.

## Accessibility

Badge text must be meaningful without relying on color alone. Keep labels short enough to scan.
