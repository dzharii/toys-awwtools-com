The published site is in dist/ at:
https://toys.awwtools.com/public/2026-11-07-fuzzy-match-algorithms-in-c99-astro-doc/dist/

For local browsing, start a server from the repository's docs/ directory:
    python3 -m http.server 8000
Then open /public/2026-11-07-fuzzy-match-algorithms-in-c99-astro-doc/dist/
on localhost:8000. Site fonts and assets are included.

The included dist/ is a deployment snapshot. A fresh Astro build uses the
original hosting configuration and will need its URLs adapted before publishing.

Read docs/measured-results.md for the recorded matching tradeoffs.
Run make feedback after a completed benchmark to refresh measured observations.
Build instructions are in README.md.
