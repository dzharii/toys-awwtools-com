These buttons change the source article's CSS viewport inside the frame. A test records the frame's actual width and height. This checks responsive layout and controls; it does not emulate a physical touchscreen.

Source lines should wrap without forcing the framed document wider than its viewport. Text size remains beside search. On a narrow page, the menu button opens navigation. Desktop resizing is checked separately on the navigation's right edge.
