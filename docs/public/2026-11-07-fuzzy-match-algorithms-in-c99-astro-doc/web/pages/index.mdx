title: C99 configuration key matching
---

The C99 program resolves configuration names against a registry of valid properties. It compares twelve fuzzy matching algorithms with an exact-normalized baseline.

```ini
database connection strng = Server=localhost;
```

The intended property is `DatabaseConnectionString`. The parser preserves `Server=localhost;` as the value. The resolver compares only the proposed name.
