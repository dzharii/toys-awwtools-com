# Documentation typography and navigation choices

This site explains a C99 parser, name resolver and benchmark. It is a technical reference and reading guide, so it uses ordinary documentation pages rather than a promotional landing page.

Astro Starlight supplies the page layout, grouped sidebar, contents list, previous/next links, Pagefind search, mobile navigation and light/dark themes. Custom code adds source line references and header text sizing and resizable navigation.

Body text uses locally served Atkinson Hyperlegible at 18px with 1.75 line height. Code uses locally served JetBrains Mono. Prose is limited to 76 characters per line. Source uses the full main column with 16-32 pixel gutters and always wraps. Three text sizes are selectable beside search. Readers resize or collapse desktop navigation on the sidebar itself. Preferences stay in browser storage and are not sent to a service.

The light palette uses paper #fcfdff, navigation #f8fafc, accent #1d6597 and accent text #174465. The dark theme uses Starlight defaults with accent #4ba2dc. Color marks links and syntax categories. It does not encode acceptance status without a text label.

Headings name the operation, source file, algorithm or measured result. The text review follows the writing-focused unslop instructions in https://github.com/cursor/plugins/blob/main/pstack/skills/unslop/SKILL.md . Literal code, reference tags, formulas and measured quantities retain their meaning.
