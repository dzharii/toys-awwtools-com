## Configure navigation, search, fonts and component overrides

The sidebar groups pages by configuration processing, algorithms, source reference and measured results. Starlight supplies routing, Pagefind search, themes and mobile popovers. Project overrides place text size beside search and navigation controls in the sidebar. Expressive Code wraps examples by default. Local font imports avoid external font-service requests.
