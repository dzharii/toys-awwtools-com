Study settings

Character voices & delivery

Each line uses its story speaker, not a random voice. Automatic casting prefers recognizable male/female voice names to match the character. The same character keeps the same pitch across Japanese and English; small delivery differences distinguish characters sharing a voice.

Web Speech does not report voice gender. Name-based casting is a best effort, and pitch alone does not turn a voice male or female. Preview both languages and override each character if needed. If no suitable voice is listed, the browser still receives the correct language request; its default voice’s gender cannot be guaranteed.

Like the reference experience, speech uses browser choice when a Japanese or English voice is not listed. Text is split by writing system: Japanese characters use ja-JP, English words use en-US, with the same character profile throughout. A browser service voice may use a network speech service; choose a voice marked “installed” for offline speech. No microphone or original anime recordings are used.

Only if browser choice also fails: on Windows, add Japanese speech in Settings → Time & language → Language & region → Japanese language options, then restart the browser. Word timing depends on the engine; without it, the whole spoken line stays marked.

Progress is stored locally when the browser permits it. Export a progress file for reliable backups.
