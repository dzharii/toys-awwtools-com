# Stilltime

Stilltime is a cinematic 3D digital clock designed to make checking the time a more enjoyable visual experience. It combines dimensional typography, animated digit transitions, subtle lighting, and four customizable themes.

The main idea is to make the clock useful beyond its browser tab. With Picture-in-Picture, you can keep a compact, animated clock floating above other applications while you work, browse, or read.

The project explores how much visual depth and interaction can be achieved using native web technologies, without external libraries or rendering engines.
