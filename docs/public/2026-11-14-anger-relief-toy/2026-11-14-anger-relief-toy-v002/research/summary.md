# Foundation research record

Research date: November 14, 2026. This foundation uses a deliberately small candidate set under the user's framework-first instruction; it is not the broad 200-candidate discovery program described for the full collection. Eleven unique candidates/concepts are recorded: eight implementations and three deferred leads. No candidate has final independent approval or a verified visual-quality score.

Initial queries covered fontBomb, Google Gravity, DOM fracture, flashlight bookmarklets, modern animation APIs, activeTab, isolated scripting, and Playwright extension contexts. A second pass compared modern fracture and Break It, then investigated Web Crawler and Katamari as different interaction mechanisms. A technical follow-up checked Web Animations forwards fill and radial gradients. The search results and direct project documentation provided behavior references; original executables were not downloaded or run. No isolated untrusted-code research environment was available.

fontBomb's public repository and experiment listing establish text scattering as a historical behavior reference. Google Gravity's own project page provides the falling-page reference. Fracture documents a shattering surface interaction; Break It was identified as a more complex alternative with Voronoi geometry. The selected foundation uses simple, independently written triangle pieces to avoid incorporating an unreviewed dependency chain. Krazete's collection lists flashlight behavior; a native CSS radial gradient implements this without original source reuse. Punch, Rubber, Screen Crack, and Vortex derive from the supplied product concept rather than a claimed external original.

The implementation decision favors native APIs, isolated packaged injection, fixed resource caps, and explicit ownership. Alternatives considered were live DOM cloning, rasterization libraries, remote bookmarklet execution, and more complex general physics engines. Snapshot illustrations have lower fidelity but avoid copying executable/custom elements, loading resources, or accessing application-private state. No source expression, library code, or third-party visual assets were incorporated. Unknown original license/version/dependency information stays unknown in the ledger.

Gaps remain: early-2000s archives, non-English discovery, original-source static review in approved infrastructure, historical publication verification, modern forks, full-category saturation, and independent visual scoring. Those gaps prevent calling this an exhaustive or source-audited collection. Expand research as new effects are proposed; do not inflate the catalog with cosmetic variants.
