# Interaction redesign, version 0.2.0

The content runtime is the authoritative owner of the equipped tool. An equipped session owns its HUD, cursor, target shield and target controls. A separate Invocations controller owns at most one effect instance. A third navigation scope owns the currently open wheel or catalog. Completing an invocation cannot destroy equipment or navigation. Closing navigation cannot end an invocation or unequip anything.

Tool state is explicit: unequipped, switching, loading, equipped/targeting, suspended or failed. Invocation state is independently idle, starting, playing, continuous or failed. Navigation is independently absent, wheel or catalog. The runtime report exposes all three. Tests exercise combinations, including playing under an open menu and idle-but-still-targeting after an explosion.

Every feature declares lifetime.class, overlap, animationMs and residueMs in its own manifest. Element tools are repeatable. The pointer flashlight is continuous, gravity is a simulation, and cracks are a persistent overlay. All use replace overlap: the next action disposes the previous invocation before allocating another. The runtime contains no effect-ID branches.

One-shot animation timings remain in individual effects. Their restoration deadline is the greater of the feature's animation plus minimum residue and the user's one-shot restore setting. It affects only that invocation. No lifetime timer is scheduled for continuous, simulation or persistent classes. End effect disposes the invocation while leaving equipment selected. Use tool restarts a document/viewport invocation after it has ended; element tools simply accept another target. Put away ends both invocation and equipment.

Scroll, resize, target removal, text replacement or geometry changes can end a snapshot invocation without losing equipment. Viewport overlays size with CSS and remain active through scroll/resize. A hidden tab suspends work, drops the active invocation and retains selection. On return, pointer-continuous modes resume; repeatable tools are ready for their next click. Simulations and persistent overlays can be deliberately restarted with Use tool. Full navigation, refresh or a route boundary discards the session. No visual state is reapplied to a new document.

Opening a menu suppresses the target shield and cursor but does not end visual activity. A modal scrim catches outside actions. Escape closes the topmost wheel/catalog; without a menu it puts the tool away. Modal focus is contained and restored. The wheel supports Tab and directional keys; element targeting cycles visible targets and inventory buttons with Tab and uses Enter on the selected target. No Again operation is required.

The wheel is a connected annulus with up to eight curated/favorite/recent choices. The native Commands API supplies the actual binding through a same-extension message. The popup and wheel display it; an absent assignment has explicit browser-shortcuts guidance. The existing Alt+Shift+A suggestion remains. The background stays stateless and injects only packaged ISOLATED files under activeTab. Its command toggles the wheel.

The on-page catalog opens at the viewport center and is draggable by its title bar, using pointer capture. Buttons, inputs and text controls do not initiate dragging. Cancel, lost capture and blur end the drag. Bounds preserve a 96px title-bar region and the Close control; resized viewports reclamp a moved panel. A title bar focused by Tab can move with arrow keys. The current document remembers position. A new document starts centered. The native browser popup remains browser-positioned and is not draggable.

Colored SVG illustrations are feature-owned and embedded into generated metadata after a build-time tag/capability check. Each render receives unique gradient IDs. The same artwork is used in all four surfaces. Generated concept images and original review footage stay in the specification assets and do not enter dist.

The optional gesture remains a P1 development prototype, not a production listener or enabled setting. It is compiled separately by bun run prototype:gesture. Its explicit opt-in uses Shift+middle on noninteractive space, requires sustained circular motion, draws a progress ring and cancels on release, pointer cancellation, blur or navigation. Ordinary links and fields are excluded. Native autoscroll/interference and branded browser validation remain unverified, so no production activation is shipped.
