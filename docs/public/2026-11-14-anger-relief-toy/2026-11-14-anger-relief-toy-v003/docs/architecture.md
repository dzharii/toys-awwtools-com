# Architecture, 0.2.0

The registry remains generated from isolated feature folders. Each folder owns metadata, an EffectModule, attribution, tests, an acceptance record and an original SVG icon. Bun validates those inputs and emits separate locally injectable IIFEs. The UI derives names, categories, icons, capabilities and lifetime behavior from metadata. No central execution switch names individual effects.

The native popup and injected catalog share rendering code. The background coordinates activeTab, scripting and storage using fixed messages and registry IDs. It answers the shortcut query through Commands.getAll and never assumes the suggested binding is assigned. It has no long-running animation state and survives service-worker restart. All animation work belongs to the isolated content world in the authorized top document.

The content runtime owns equipped-tool state and navigation state independently. An equipped scope owns the HUD, cursor, target shield and input handlers. Navigation has its own scope and epoch so late asynchronous catalog/wheel completion cannot recreate a dismissed menu. An Invocations controller owns only the current EffectInstance, AbortController, stage, animations, target observers and one-shot restoration deadline. Ending that controller never unequips the tool. Separate epochs invalidate late module-loading and invocation-start completion. The approved V1 registration bridge remains private to the extension's isolated world.

Resource scopes provide idempotent reverse cleanup and exception containment. Repeated input uses replace overlap, disposing the previous invocation before allocating another. Continuous, simulation and persistent lifetimes have no timeout. One-shot lifetime settings apply only to animations/residue. Idle equipped element tools have event-driven targeting but no animation loop, recurring timer, whole-document observer or continuous DOM scan. Target enumeration is bounded and only runs on explicit selection/keyboard actions. The released runtime retains only its message listener and cached modules.

Targets are passed through EffectTarget. Element resolution uses current rectangles and bounded open-shadow traversal; protected form/editable/embedded subtrees are excluded. A shared snapshot helper draws at most 500 nodes and 240 words without cloning executable markup or loading assets. Text Bomb has 65 words, Shatter ten pieces, impacts eighteen sparks, and Gravity twelve bodies. Snapshot effects hide only their owned visibility property and restore it without overwriting a changed host value. Native browser pixel/memory budgets remain a release gate.

Menus, HUD, cursor, outline, shield and effects have a deliberate stacking order. Menus suppress aiming/cursor input without terminating visual activity. A scrim intercepts outside clicks, focus is contained/restored, and Escape handles the topmost layer. The centered catalog supports pointer capture and keyboard movement, with viewport clamping and document-local position memory. Its native popup counterpart is not movable.

Icon rendering is shared. Build-time SVG validation rejects executable elements, external references, event handlers and styles; each render gets unique gradient IDs. Colored artwork is original editable SVG. Generated exploration images, reference recordings, source research and development gesture code never enter dist.

Diagnostics are limited to 100 local allowlisted events with catalog effect versions, runtime version, per-equipment correlation and durations. No page text, HTML, selector, URL, credentials or raw exception content is accepted. Preference storage errors cannot terminate an otherwise working tool. No remote telemetry, runtime dependency, host permission expansion or MAIN-world code was added.

Detailed state transitions, policies and integration semantics are in docs/interaction-003.md. The original baseline and new change request remain byte-identical; implementation status and review evidence are separate artifacts.
