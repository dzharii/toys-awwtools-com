# Architecture, 0.3.0

Bun discovers feature folders, validates metadata, icons and named audio layers, and emits one lazy injectable IIFE per effect. The generated catalog contains inexpensive descriptions and local SVG/audio metadata. No core execution switch imports or names concrete effect engines. Release builds reject review-pending entries.

The native popup and on-page catalog share rendering. The background handles activeTab, isolated injection, storage coordination, and the actual Commands API shortcut assignment. It accepts fixed messages and catalog IDs, never arbitrary script paths. It owns no animation or audio state.

The document Runtime is the equipment authority. Equipment owns the stable HUD, event-driven targeting, cursor and outline. Navigation owns its dialog, drag/focus resources and audio scope. Invocations owns a single active EffectInstance, AbortController, overlay, animations, observers, audio scope and repeatable restoration deadline. Distinct epochs prevent late loading or menu rendering from recreating canceled work. End effect never unequips; switching or Put away disposes the appropriate owners.

Resources provides idempotent reverse cleanup, event/RAF/timer/animation/node ownership and ownership-aware style restoration. Replace overlap bounds active effect work at one instance. Continuous/simulation/persistent modes have no generic timeout. Idle equipment has no recurring animation, whole-document observer or DOM scan. Active document target enumeration and snapshots have explicit bounds. A fixed set of document lifecycle and optional hold listeners remains in the already authorized context, including after UI dismissal, so opt-in invocation can work without a popup round trip.

AudioService owns one lazy context with master gain/compression, cached deterministic noise, at most eight source voices and separately cancelable owners. Typed effect-local audio.json defines original synthesis layers; the SDK exposes named play/stop only. Features never create audio contexts. Delays use the audio clock. Mute, live volume, category controls, failed initialization, future source cancellation, suspended contexts and disposal are tested. Shared dial audio is independent of invocation cleanup.

DialModel provides bounded physical slots over an arbitrary logical registry. The menu freezes ordering for its lifetime. At most nine buttons rotate through the NW mask; icon and label counter-rotation keeps them upright. A stationary SVG retaining arm and matching48-degree conic mask conceal identity replacement. Pointer angular movement, a6px drag threshold, short detent settlement, keyboard focus and current-ID selection are separate from catalog indexing. No effect implementation is loaded by browsing the dial.

MiddleHold is an opt-in production service in the authorized document, initially disabled. It qualifies noninteractive middle-button presses, renders elapsed-time progress, cancels early release/movement/focus/visibility/navigation, and opens the same dial. Settings explain native autoscroll/paste replacement on eligible areas. Real links, controls, fields and extension UI are excluded. Primary targeting uses capture listeners rather than an opaque all-button shield, preserving native middle links and keyboard activation.

Shared DOM/icon/focus/position helpers serve all UI surfaces. Shadow DOM and a deliberate layer policy isolate menus, inventory, aiming cues and visuals. The catalog opens centered and supports constrained titlebar dragging and keyboard movement. Original SVG artwork receives unique gradient IDs; executable or remotely referenced SVG is rejected at build time.

Diagnostics remain bounded to100 local sanitized records. Versions come from metadata, with runtime0.3.0. No page text, full URL, HTML, selector, form value or raw exception content is logged. Settings are optional and storage failure cannot invalidate a running tool. All permissions remain activeTab, scripting and storage; no MAIN-world or remote runtime code is introduced.

Details and tradeoffs are in interaction-004.md. Historical specifications and assets are immutable. Current verification separates component results, inspected static prototypes and blocked native browser evidence.
