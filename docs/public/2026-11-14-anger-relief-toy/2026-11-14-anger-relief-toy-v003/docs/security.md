# Security and provenance

Only activeTab, scripting, and storage are requested. Injection is user-triggered, top-frame-only, and explicitly ISOLATED. There are no host permissions, remote executable files, dynamic imports from websites, web-accessible scripts, or production npm dependencies. Original third-party executable samples are neither stored in this repository nor executed. Research references are documentation only.

The production boundary contains only project-owned TypeScript, HTML, CSS, generated metadata, and original icons. The package script includes only `dist`. It excludes research artifacts, tests, node_modules, local browser profiles, source attachments, and tooling. The source archive separately retains the supplied materials for review; its HTML conversation export is historical data, not an executable product component.

The background validates command names, sender extension ID, main-frame identity where applicable, and effect IDs against the generated registry. It never accepts script paths, source strings, DOM objects, or arbitrary page-supplied commands. The content listener accepts same-extension messages only. Per-feature entries register in the isolated world, not MAIN. Browser-internal pages, web stores, and revoked activeTab grants return a generic unsupported-page error. File access depends on the user's separate browser extension setting.

Element targeting intercepts deliberate primary-pointer down/up/click/double-click in capture listeners while equipped. Extension UI is excluded. Keyboard-generated clicks and middle-button events remain native; the opt-in hold service changes only its documented eligible middle presses. No host event is synthesized or forwarded. The underlying page's arbitrary global capture handlers remain outside the extension's control; this does not guarantee protection against a hostile page observing every input. Ordinary live controls are never programmatically clicked. Sensitive form values and editable descendants are excluded from snapshots and target enumeration. This extension is for trusted browsing, not a sandbox for hostile websites.

Original assets are produced locally with vector paths and pixel primitives; no external font, image, texture, or recorded sound sample is packaged; original sound profiles use only shared Web Audio synthesis. Historical references have unverified original-source licensing, explicitly recorded in metadata. No code is adapted from those projects. This removes redistribution of their executable expression from the foundation, but does not substitute for the independent provenance/rights review required before production release.

Development dependencies are exact-versioned in `bun.lock`. Happy DOM tests evaluate only the trusted compiled project in an emulator; they are not an isolation system or a substitute for native Chromium. Do not use those tests to investigate untrusted bookmarklets. Security lint is a guardrail and cannot replace review.
