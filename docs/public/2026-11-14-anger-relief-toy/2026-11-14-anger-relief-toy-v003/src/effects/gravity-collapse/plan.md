# Increment004 audio integration review

A soft detachment cue starts the simulation. Actual floor collisions request a bounded low thump, with130ms minimum separation and velocity-dependent strength. Resting bodies are silent.

The original visual interaction, shared colored icon, scope and repeatable/continuous lifetime are preserved. Audio uses the typed project-wide service and local audio.json with no independent context, external assets or dependencies. Replacement, End effect and Put away dispose owned sources. Master volume defaults to20%, with global mute and category controls.

Contract, runtime and audio-node tests establish synchronization requests and cleanup. Native output, material fidelity and repeated-use listening comfort remain unverified because Chromium startup is blocked. This plan/review does not confer final production acceptance.
