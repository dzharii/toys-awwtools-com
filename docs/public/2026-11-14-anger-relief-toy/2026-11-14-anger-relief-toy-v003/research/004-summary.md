# Research record: feature 004 candidates

Research date: 2026-11-15. This is concept research, not a source-code security audit or a claim of production approval. Original third-party bookmarklets were neither downloaded nor executed. No third-party implementation or artwork was copied. Exact source revisions are unknown unless subsequently pinned; public availability is not a redistribution license.

The initial ten concepts selected for independent reconstruction are Wrecking Ball, Burn the Page, Disintegrate, Page Dance, Celebration Cannon, Three-Dimensional Page, Television Glitch, Color Splash, Snowfall and Matrix Rain. Their implementation and individual quality gates remain separate work.

The [machine-readable record](004-candidates.json) separates source observations from proposed mechanics, feasibility and rights uncertainty. The selected concepts span targeted impacts, local transformations, continuous environmental overlays and multi-target choreography. Their shared visual vocabulary must not turn them into generic copies of one particle effect.

Alternative discovery considered the Sick Set Tri layered-page concept alongside DevBubba 3D, Web Pranks All Fall Down alongside existing Gravity, and the overlap between both arcade game candidates. All Fall Down was not added as a separate tool because Gravity already addresses falling-content play. Tri reinforces depth as a credible independent interaction but is not a second 3D tool. The original Harlem Shake music is excluded.

Primary documentation retrieval limitation: DevBubba documentation was available in indexed primary-source search excerpts, while direct retrieval returned 404 in this environment. Its collection is a concept lead, not verified code or rights provenance. Katamari direct repository retrieval also failed; the indexed primary project landing-page documentation supplied the spatial-grid observation. No claim is made that current upstream code is secure.

Known source licensing: Burn the Web and Disintegrate primary repository descriptions identify MIT. Other sources remain unknown here, so only general interaction ideas are used. Unknown terms do not authorize copying code or artwork. Future code reuse requires pinning the exact commit, preserving its actual license text, static security review and the project isolation procedure if dynamic execution is needed.
