# Anger Relief Toy

A browser extension with eighteen temporary visual tools for ordinary webpages:
punch a comment, scatter words, crack a surface or move a spotlight.

- [Read the illustrated guide](index.html) for the tools, three-version history,
  installation instructions and practical limitations.
- [Download project release 0.0.3](downloads/anger-relief-toy-v003.zip), extract it,
  then load the folder containing `manifest.json` in Chrome or Edge's Extensions
  manager. The unchanged manifest reports **0.3.0**.
- All three original version folders remain available. `v003/dist` is current;
  `v001` and `v002` preserve the earlier eight-tool stages.
- [Implementation and verification](docs/landing-005-implementation.md) records
  authentic screenshot provenance, browser observations and remaining limits.

The guide is a static page with local images, no JavaScript, and no build step.
The extension uses local rendering and sound synthesis. It is supplied for
review, not as a compatibility or safety certification.
