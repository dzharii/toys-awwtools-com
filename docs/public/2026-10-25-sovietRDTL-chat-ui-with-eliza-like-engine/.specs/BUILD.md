# AY00. Сборка, проверки и переносимый пакет

Минимальные средства: Node.js 22+, Python 3 для HTTP-сервера и ZIP. Приложение не имеет runtime-зависимостей. `npm run validate` проверяет актуальные каталоги, `npm run release` создаёт dist из исходников, `npm test` выполняется после release и использует Node test runner. Для браузерных тестов нужны `npm ci`, поддерживаемые браузеры Playwright и рабочий HTTP/HTTPS URL.

Релиз копирует HTML/CSS/ES-модули и используемые WebP, экспортирует минимизированные JSON с content-hash в имени и manifest с SHA-256/байтами/версией. До справки загружаются manifest и runtime; origin chunks запрашиваются лениво с повтором после ошибки. Словари и схема также доступны как самостоятельные ресурсы. Отчёт офлайн gzip/Brotli не называется фактическим сетевым измерением. Хостинг должен поддерживать корректные MIME, HTTPS и CSP с локальными blob для media/img.

Приёмка включает схему/ссылки/текстовые дубли, обращения на «ты», целые грамматические формы, safety до RNG, тематические и многосообщенческие примеры, статистику реальных генераций, ресурсные гонки, сохранение обычной истории и полное исчезновение медиаэпизодов. Справка проверяется по фактическим частям ответа. Изменившийся прогон не наследует старую редакционную оценку автоматически.

Playwright должен проверять 360/390/768/1280/1440, три интонации, короткое и длинное opening, панель, перезагрузку, ошибки данных, запись/остановку/отправку, импорт/paste/отмену, плеер/перемотку/скачивание и временное хранение. Тестовый WAV и искусственный recorder не заменяют настоящий микрофон компьютера/телефона. Непройденные или недоступные проверки честно отмечаются; production gate не ослабляется ради сборки. Проверка происхождения, прав и независимая редактура остаются отдельными критериями.

`npm run package:source` создаёт ZIP с корневым каталогом sovet-rdtl. Выбор файлов разрешительный: актуальный src/data, используемые registry-WebP, HTML/CSS/favicon, package/lock, README, agents/AGENTS, эти краткие спецификации, документация формата, активные инструменты и необходимые тестовые данные. ARCHIVE.json перечисляет состав с SHA-256 и размерами. Уже сжатые WebP не перекодируются в JPEG повторно. Обычный текст/JSON сжимается ZIP Deflate без потери редактируемости.

Исключаются node_modules, dist, .git, .openai, credentials, исходные большие PNG, reference images, снимки, старые release-assets, TSV-импорты, полная переписка/старые спецификации и журналы прогонов. Небольшие синтетические PNG/WAV входят как используемые фикстуры, не как reference images. Метаданные происхождения выражений сохраняются полностью. Пакет не привязан к чужому хостингу.

После упаковки архив проверяется на целостность, безопасные относительные пути, наличие всех используемых ассетов и предел 10 МиБ. Затем распаковывается в чистый каталог, где заново выполняются validate/release/Node-тесты. Это подтверждает, что исключённые файлы не нужны для восстановления сборки. Публикация обновлённого сайта выполняется отдельно в выбранное назначение с сохранением текущего доступа.
