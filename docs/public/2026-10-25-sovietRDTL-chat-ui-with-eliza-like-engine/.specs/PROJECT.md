# AV00. Проект и визуальная модель

СоветРДТЛ представляет разговор с одним строгим бытовым родителем. Основная аудитория может быть взрослой, а роль пользователя в диалоге называется «Ребёнок». Юмор возникает из узнаваемых родительских реакций при серьёзном современном виде приложения. Интерфейс не объясняет шутку. Все родительские обращения используют «ты», включая одесские конструкции, варианты и подготовленные формы. Отказ звучит прямо, без почтительного «я попросил».

Приложение статическое, без runtime-зависимостей, серверной генерации и вызова языковой модели. HTML, CSS, ES-модули и Web Components. Слои: domain для содержания и грамматики, app для сценариев чатов, adapters для каталогов/хранилища/локальных ресурсов, media для записи и проверки форматов, ui для отображения. RNG, часы, ID и задержки внедряются. Декоративный выбор фона не расходует разговорный RNG.

Сохраняется только тёмная тема. Слева список чатов, в центре прокручиваемая история, внизу форма ввода. На телефоне навигация раскрывается отдельно и удерживает клавиатурный фокус. Каждый ответ имеет подпись «Родитель», каждый пользовательский ввод «Ребёнок»; в модели роли assistant/user. Пользователь выровнен вправо на отдельной тёмной поверхности, родитель влево.

Три уровня текста: пользователь 16 px; обычный родитель 20 px на компьютере и 19 px на телефоне; opening 36/27 px, длинный opening 32/25 px. Вступление является настоящим сообщением и не уменьшается после отправки, переключения или перезагрузки. Строки ограничены центральной колонкой, переносы не создают горизонтальную прокрутку.

Интонация задаётся данными: ironic тёплая, strict светлая с более сильным начертанием и сплошной линией, sarcastic с холодным розовато-фиолетовым акцентом и наклонным начертанием/пунктирной линией. Цвет не единственный признак. Silence нейтрален. Целевой контраст обычного текста не ниже 4.5:1. Произвольного выделения слов по пунктуации нет.

Фон выбирается при создании чата и сохраняется как backgroundId. Используются 20 интерьерных изображений, каждое в desktop/mobile WebP. Картинка приглушена отдельным слоем, не принимает события и не влияет на размеры. На телефоне менее заметна. При ошибке остаётся однотонный тёмный фон. В хранилище не записывается сама картинка.

Справка открывается видимой кнопкой справа сверху ответа в закрываемой правой панели. Поддерживаются Escape и возврат фокуса. Содержимое объясняет конкретную фразу человеческим языком. Для составного ответа показываются фактические части, а не технические шаблоны. Silence не имеет справочной кнопки. Панель не содержит повторяющихся оговорок о неизвестной атрибуции: честные исторические статусы хранятся в данных.
