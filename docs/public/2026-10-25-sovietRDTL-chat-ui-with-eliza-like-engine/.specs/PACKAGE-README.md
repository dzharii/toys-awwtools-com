# AZ00. Основные спецификации исходного пакета

[AV00. Проект и визуальная модель](PROJECT.md) задаёт продукт, архитектуру и оформление.

[AW00. Данные, словари и грамматика](DATA.md) описывает актуальные наборы, поля и происхождение.

[AX00. Разговор, история и локальные вложения](BEHAVIOR.md) определяет сценарии, память, вероятности и жизненный цикл.

[AY00. Сборка, проверки и переносимый пакет](BUILD.md) описывает восстановление и приёмку.

[AU00. Единое обращение и родительская прямота](register-style.md) фиксирует последующее уточнение характера речи.

Это компактный актуальный контракт для воспроизведения проекта. Историческая переписка, старые редакции и reference images в исходный ZIP не включаются. У каждого раздела неизменяемый буквенный код; новая секция начинается с 00, при изменении увеличивается только её ревизия.
